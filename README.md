# padAdmin

### 简介 📖

> padAdmin 是一个免费开源的中后台模版。使用了最新的 vue3,vite2,TypeScript 等主流技术开发，开箱即用的中后台前端解决方案，也可用于学习参考。该仓库有三个分支
>
> - dev 分支为 vue3 版本
> - react 分支为 react 版本 react18 + typescript + redux + antd
> - rtk 分支为 react 版本 react18 + typescript + react toolkit + antd(react 后续维护同步更新的版本)

## 特性 🌰

- **最新技术栈**: 使用 Vue3/vite2 等前端前沿技术开发
- **TypeScript**: 应用程序级 JavaScript 的语言
- **权限**: 内置完善的动态路由权限生成方案
- **组件**: 二次封装了多个常用的组件

### 安装使用 📔

- 获取项目代码

```bash
   git clone https://gitee.com/zhiguangyan/padAdmin.git
```

- 安装依赖

```bash
   cd padAdmin
   yarn
```

- 运行

```bash
   (vue版本) yarn dev
   (react版本) yarn start
```

- 打包

```bash
   yarn build
```
